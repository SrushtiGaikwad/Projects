Project Name: Youtube Chatbot using Langchain
README – Project Description

This project is a RAG (Retrieval-Augmented Generation) based YouTube Chatbot built using LangChain that allows users to interact with YouTube video content in a conversational manner. The application extracts transcripts from YouTube videos, converts them into vector embeddings, and stores them in a vector database for efficient semantic retrieval. When a user asks a question, the system retrieves the most relevant chunks from the video transcript and uses a Large Language Model (LLM) to generate accurate, context-aware responses. This project demonstrates practical usage of LangChain, embeddings, vector stores, and LLM-based question answering, showcasing how RAG can be applied to real-world conversational AI applications.
Tech Stack: python, LLM - Gemini, gemini api, Langchain-components, FAISS(vector store), streamlit, Youtube TranscriptApi
